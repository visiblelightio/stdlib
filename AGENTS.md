### Markdown

When creating or editing Markdown, use semantic line breaks to keep future diffs local.
Put each prose sentence on its own source line, with optional breaks at clause boundaries.
Keep existing semantic breaks and indent continuation lines within list items.
Use blank lines for paragraph boundaries and preserve the syntax of tables and code blocks.
